# Edu Predict
EduPredict is a machine learning application that predicts student academic performance from educational, behavioural, and demographic factors.  The project uses Python, pandas, NumPy, and scikit-learn to explore student performance data, preprocess numerical and categorical features, train and compare multiple machine learning models, and evaluate their predictive performance.  Key Features Exploratory data analysis and visualisation Automated preprocessing of numerical and categorical features Multiple machine learning models for performance comparison Cross-validation and model evaluation Feature importance analysis Interactive predictions through a web interface Clear visualisation of model performance and results Technologies Python pandas NumPy scikit-learn Matplotlib Streamlit  The project is designed to demonstrate a complete machine learning workflow, from raw dataset exploration and feature engineering through to model training, evaluation, and deployment.
